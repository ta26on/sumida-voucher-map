# すみだ商品券 店舗検索（検索画面プロトタイプ）

公式店舗一覧から生成した737掲載レコードを収録した、依存ライブラリ不要の静的Webアプリです。

## 起動

このフォルダで次を実行してください。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。`index.html` をファイルとして直接開くと、ブラウザの制限でJSONを読み込めない場合があります。

## 収録データ

`stores.json` は `../sumida_phase1/store_import_candidates.csv` から `build.py` で生成しました。A・B券共通703件とB券のみ34掲載項目を収録しています。B券のみの掲載項目には施設・チェーン単位の記載も含み、737はユニークな店舗数ではありません。
