# すみだ商品券 店舗検索（検索画面プロトタイプ）

公式店舗一覧から生成した737掲載レコードを収録した、依存ライブラリ不要の静的Webアプリです。

## 起動

このフォルダで次を実行してください。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。`index.html` をファイルとして直接開くと、ブラウザの制限でJSONを読み込めない場合があります。

## 収録データ

`stores.json` は `../sumida_phase1/store_import_candidates.csv` から `build.py` で生成しました。A・B券共通703件とB券のみ34掲載項目を収録しています。B券のみの掲載項目には施設・チェーン単位の記載も含み、737はユニークな店舗数ではありません。

## 現在地から近い順に表示する

「現在地から近い順」を押し、ブラウザで位置情報の利用を許可すると、絞り込み結果のうち座標登録済みの店舗を直線距離順で表示します。座標未登録の掲載項目はその後に続きます。位置情報はページ内の距離計算に使い、サーバーへの送信や共有URLへの追加は行いません。再読み込みすると通常の掲載順に戻ります。

### 店舗の位置データ

[store-locations.json](store-locations.json) に、場所を確認できた個別店舗の緯度・経度と確認元URLを `record_id` ごとに記録します。追加時は公式の店舗ページで店舗名と住所を照合し、地図のピンの位置を確認します。Googleマップの店舗を特定できるCIDも確認できた場合は、文字列の `googleMapsCid` として追加します。詳細画面のリンクは、店舗のスポット、座標のピン、住所検索の順で利用できる情報を使います。

## 現状の制限

- 座標は一部の個別店舗のみ登録済みです。
- 共同編集・ログイン・現地確認投稿は未実装。
- 公式掲載情報は現在の利用可否を保証しません。
- 地域は住所から簡易抽出しているため、一部に表記揺れがあります。
- 開発用の試作です。公開前に公式データの再配布条件を確認してください。
